# Financial Itinera Calculator

Financial planning calculator code library to simulate any kind of future planning scenario.

A GPL-v3 licensed coding library with pre-coded examples to enable engineers to simulate and calculate their own
financial planning scenarios.

## Conceptual Overview

Financial Itinera Calculator is an open source, extentable, and high-quality financial planning simulation library that
allows individuals or CFPs to simulate any imaginable wealth planning scenario around the most basic building financial
building blocks: Assets, Liabilities, and Transactions.
